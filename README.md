# ReWear Blocks Business Proposal

Interactive website-based proposal presentation for the fictional **ReWear Blocks | LEGO x Patagonia** concept.

## Folder Structure

- `index.html` - interactive presentation website
- `styles.css` - responsive deck styling
- `script.js` - slide navigation, tabs, gallery, and progress interactions
- `presentation_script.md` - separate 5-minute spoken presentation script
- `assets/` - source website images and newly generated product images

## How To Open

Open `index.html` in a browser. The presentation supports:

- Previous / next slide buttons
- Top navigation and slide menu
- Keyboard navigation with left and right arrow keys
- Clickable persona tabs, MVP feature cards, experiment tabs, and product gallery
